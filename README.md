# pantry-research

An experiment program: can agents on different harnesses (Pi, Think, OpenCode, a plain Worker) coordinate by sharing deterministic recipes, and get better together as a shared cookbook grows?

The substrate under test is [pantry](https://pantry.coey.dev). It stores recipes; it never runs them.

| File | What |
|---|---|
| `program.md` | The question, and the experiment ladder worked backward from the north star |
| `LOOP.md`, `TERRALOOP.md` | How one experiment is run and recorded |
| `findings.md` | What each experiment showed, including failures |
| `status.json` | Current state of the ladder |
| `experiments/` | One folder per experiment, with code and receipts |

## Status

Research, not a product. Read `findings.md` before you trust any claim here.
